# Project Roshni — Website

A static, informational landing page for Project Roshni, built from the sponsorship proposal.

- `index.html` — all content, one section per category (Mission, Requirements, Fundraising, Marketing, Sponsorship, Budget, Testimonials, Contact & Team)
- `styles.css` — theme (teal-to-navy gradient, cream background, gold accents)
- `script.js` — mobile menu and active-section highlighting
- `assets/` — logo and favicon

Every section has its own link (e.g. `index.html#testimonials`) that can be shared directly.

To view, open `index.html` in a browser. To publish, enable GitHub Pages on this repository (Settings → Pages → deploy from branch, root folder) or upload the folder to any static host.
